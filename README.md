NEON HARBOR is an original top-down open-world crime game set in the sun-soaked port city of Port Aurelia. It runs offline in a desktop browser from static files: walk the sidewalks and steal cars, outrun the Aurelia patrols as your wanted level climbs, and run four story missions for the fixer Marlow — from a first meeting at the Harbor Docks to the big score at Aurelia Savings Bank. Traffic follows the roads, pedestrians flee danger, and the Safehouse saves your game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step and no network requests: the game is the plain files under `game/`, and all of its sound is synthesised live with WebAudio.
